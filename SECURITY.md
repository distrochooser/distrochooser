# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 6.x (currently distrochooser.de)  | :white_check_mark: |
| 5.x (currently old.distrochooser.de)¹  | :x:|
| 4.x (offline)   | :x:    |
| 3.x (offline)  | :x:                |
| 2.x (offline)  | :x:                |
| 1.x (offline)  | :x:                |

¹ Distrochooser 5 is online, but planned for shutdown: https://github.com/distrochooser/distrochooser/releases/tag/6.9.0


## Reporting a Vulnerability

Please give me a ping to distrochooser-security@chmr.eu if you have found any security issues in the project. Emails without proper initial information will be discarded without comment.

Thank you!
